`minor release` · June 11, 2026

---

## 🚀 New Features

- **Expanded RDS and Aurora Management**  
  RDS dependencies can now be restored to a specific point in time and use custom parameter groups. Storage encryption is enabled by default, with custom KMS keys, Performance Insights and snapshot restore for Aurora PostgreSQL.

- **Kafka Authentication Options**  
  Kafka (MSK) dependencies can now be created with IAM or SCRAM (username/password) authentication, in addition to no client authentication.

- **Multiple EFS File Systems per Cluster**  
  EFS is now managed as a cluster addon and supports more than one file system per cluster. Clusters with legacy storage classes are migrated automatically to the current ones.

- **AI Cost Breakdown by Product**  
  AI spending history is now broken down by product (chat, autodiagnostics, reports, etc.). Report requests check the AI budget limit up front and show a link to adjust it when reached.

---

## ✨ Improvements

- **Resource Details Everywhere**  
  Resource details can be opened from any screen and expose the same actions available in tables. Migration completion notifications link directly to their detail.

- **Billing Screen Improvements**  
  Billing loads faster, groups costs by resource type and shows costs per nodepool in each cluster's detail.

- **BuildKit Migration for Production Projects**  
  Production projects still using Kaniko are notified in advance and then migrated to BuildKit.

- **More Reliable Log Compaction**  
  The Loki and LokiV2 addons now provide persistent storage to their compaction component, so it runs without errors.

---

## 🐛 Bug Fixes

- **Activity Log Accuracy**  
  Volume and workload actions now produce a single entry on the correct resource, and project clones are recorded and can be filtered.

- **SSL Certificate Validation**  
  Validating an environment domain's SSL certificate now consistently creates the deployment pending approval.

- **Spellcheck Disabled on Sensitive Fields**  
  Fields holding secrets (variable values, API keys, tokens, kubeconfig, AWS keys) no longer send their content to the browser's spellchecker.

- **S3 Bucket Name**  
  S3 dependencies now always use the actual bucket name instead of assuming it matches the dependency name.

- **Hidden Table Filters**  
  Hidden filters are now kept in the URL, so filtered table views survive a refresh and can be shared.
