`minor release` · July 16, 2026

---

## 🚀 New Features

- **Addon and Environment Import/Export**  
  Adopt Helm releases already running in your cluster as SleakOps Addons, create custom Addons from JSON, and export or import the resources of a project or environment.

- **Accounts & Networking Explorer**  
  A new section, opened from the Providers list, shows each Account of a Provider and a read-only view of its networking (VPC, subnets, NAT and Internet gateways).

- **Support Partners**  
  Companies working with a support partner now get their support and diagnostic tickets routed to that partner, with the partner's branding in the support button and ticket drawer.

---

## ✨ Improvements

- **New Webservices Form for Everyone**  
  The redesigned webservices form is now enabled for all users and replaces the previous one.

- **Simpler Account Selection**  
  The sidebar lists only accounts that have at least one cluster and auto-selects the account when only one is available.

- **Improved AI Reports**  
  Infrastructure diagrams now render instead of showing raw code, every report can be printed to PDF, and all reports share a consistent layout.

- **Redis Cluster Monitoring**  
  Metrics now work for Redis dependencies in cluster mode, with a tab for each member of the replication group.

- **EFS Addon Update**  
  A new version of the EFS Addon with an updated CSI driver is available, and file systems with associated volumes are protected against changes that would break them.

---

## 🐛 Bug Fixes

- **Volume Deletion**  
  Deleting a volume still mounted by a pod now retries until it is released, or ends in a clear error instead of failing silently.

- **Dependency Creation Errors**  
  The real validation error is now shown when creating a dependency fails, instead of a generic message.

- **Dockertron Presets**  
  Fixed worker commands, dependency variable names, and n8n settings in Dockertron presets.

- **Billing Forecast Comparison**  
  Cost summary cards now compare the forecast against the full previous-month total, fixing inflated percentages.

- **Mobile Dashboard Font Size**  
  Fixed text that was too small on the dashboard on mobile devices.
