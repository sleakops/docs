## ✨ Improvements

- **Sticky Sessions Tutorial for Web Services**  
  New guide on enabling sticky sessions in a Web Service through its ingress annotations, including when stickiness is the wrong tool and how to verify it.

- **Cost Review Guide**  
  New tutorial on reading your AWS spend with the Cost Explorer, Kubecost, and Cost Allocation Tags before deciding what to optimize.

- **Support Scope Page**  
  New page explaining how to reach Support, what it covers, and where to look first for common questions, aligned with the Responsibility Model.

- **Exhaustive Environment Testing Guide**  
  New checklist of tests to validate that your application is fully functional after migrating to a new SleakOps infrastructure.

- **Database Encryption Documentation**  
  The dependency docs now accurately describe at-rest encryption defaults, opt-out, and custom KMS key options for database dependencies.
