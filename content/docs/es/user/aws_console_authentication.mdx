# Autenticación de la Consola de AWS

:::tip [VIDEO] 
Cómo acceder a cualquiera de tus Cuentas.

Como se describe en la [Descripción General de la Arquitectura](/docs/provider/accounts), primero debes ingresar a la cuenta 'security' y luego asumir el rol de la cuenta a la que quieres acceder. La forma más simple de hacerlo es usando el [Panel de SleakOps](https://console.sleakops.com/):

Primero, en la tarjeta **Get AWS and VPN Access** del panel, haz clic en el botón **Login** (usa el usuario IAM que se muestra al lado):
<Zoom overlayBgColorEnd="rgba(255, 255, 255, 0.8)">
  <img src="/img/users/USER-aws-login.png" alt="USER-aws-login" style={{ height: '200px', width: 'auto' }}/>
</Zoom>

Esto abrirá el formulario de inicio de sesión de AWS. El campo Account ID debería completarse automáticamente con el ID de la cuenta 'security'. Si esto no ocurre, puede deberse a que otro servicio está intentando completar los campos.

<Zoom overlayBgColorEnd="rgba(255, 255, 255, 0.8)">
  <img
    src="/img/users/USER-aws-security-login.png"
    alt="USER-aws-security-login"
    style={{ height: "300px", width: "auto" }}
  />
</Zoom>


Una vez que hayas iniciado sesión en la cuenta 'security', verás algo como lo siguiente:

<Zoom overlayBgColorEnd="rgba(255, 255, 255, 0.8)">
  <img
    src="/img/users/USER-aws-console-initial.png"
    alt="USER-aws-console-initial"
  />
</Zoom>


Ahora, vuelve al panel de SleakOps y, en la misma tarjeta **Get AWS and VPN Access**, haz clic en el botón **AWS Account Switcher** junto a la cuenta a la que quieres ingresar.

<img src="/img/users/USER-get-access.png" alt="USER-get-access"  style={{ height: '200px', width: 'auto' }}/>
<img src="/img/users/USER-account-switcher.png" alt="USER-account-switcher"  style={{ height: '400px', width: 'auto' }}/>


Esto abrirá una nueva pestaña de AWS para cambiar de rol desde tu cuenta 'security' hacia la cuenta seleccionada: saldrás de la cuenta 'security' e ingresarás a la elegida.

<Zoom overlayBgColorEnd="rgba(255, 255, 255, 0.8)">
  <img
    src="/img/users/USER-switch-role.png"
    alt="USER-switch-role"
    style={{ height: "250px", width: "auto" }}
  />
</Zoom>

:::info
Si ya estás dentro de 'security' o de otra cuenta, puedes usar directamente los selectores de cuenta: AWS entiende que ya estás dentro de la cuenta 'security'.
:::

Para más información sobre este proceso, puedes leer la [documentación de AWS <FiExternalLink/>](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_use_switch-role-console.html).
