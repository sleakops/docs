# Dockertron

Dockertron analiza tu repositorio y genera todo lo necesario para correr tu aplicación en SleakOps: Dockerfiles listos para producción, una configuración de docker-compose y el modelo completo de infraestructura — sin escribir archivos de configuración ni copiar templates.

## Preguntas frecuentes

<details>
<summary>
### ¿Dónde encuentro Dockertron?
</summary>
Dockertron no tiene una entrada propia en la barra lateral. Accedé desde **Projects**: hacé clic en **Dockertron IA** en el encabezado de la página, o usá el aviso **Configure your project with Dockertron AI** cuando la tabla de Projects está vacía. Cualquiera de los dos caminos abre el drawer de creación en `/dockertron`, que también lista tus ejecuciones anteriores — repositorio, rama, estado y fecha de creación.
</details>

<details>
<summary>
### ¿Cómo inicio una ejecución de Dockertron?
</summary>
1. Desde **Projects**, hacé clic en **Dockertron IA** en el encabezado (o en el aviso **Configure your project with Dockertron AI** cuando la tabla está vacía).
2. Completá el formulario de dos pasos:

<Zoom overlayBgColorEnd="rgba(255, 255, 255, 0.8)">
  <img
    src={require("./dockertron/dockertron-ia-form.png").default}
    alt="dockertron-ia-form"
  />
</Zoom>

**Paso 1 — Project Source:** Seleccioná el repositorio privado y la rama a analizar.

**Paso 2 — Quiz Details:** Proporcioná contexto adicional para refinar la generación (lenguaje, framework, configuraciones especiales).

3. Hacé clic en **Generate projects with AI**.

:::info
Solo los repositorios privados están disponibles para ejecuciones de Dockertron.
:::
</details>

<details>
<summary>
### ¿Qué genera Dockertron?
</summary>
Para cada repositorio que procesa, Dockertron produce:

- Un **Dockerfile** por servicio detectado, optimizado para producción (imagen base, dependencias, healthchecks, comando de inicio)
- Un **docker-compose.yml** que conecta todos los servicios
- El **modelo de infraestructura de SleakOps** — workloads, dependencias y variables de entorno listos para importar en la consola
- Un **README** con instrucciones para correr el proyecto localmente

Revisá cada archivo generado directamente desde la página de detalle de la ejecución. Si la creación de Pull Request está habilitada para tu cuenta, esos mismos archivos también se entregan como un Pull Request en tu repositorio.
</details>

<details>
<summary>
### ¿Qué lenguajes y frameworks son compatibles?
</summary>
Dockertron funciona con cualquier lenguaje y framework — vos proporcionás el contexto en el paso Quiz Details. Ha sido ampliamente probado con Python (Django, FastAPI, Flask), Node.js (Express, Next.js), Go, Java (Spring Boot) y Ruby on Rails.
</details>

<details>
<summary>
### ¿Cuánto tarda una ejecución?
</summary>
Generalmente entre 5 y 30 minutos dependiendo del tamaño y la complejidad del repositorio. El estado no se actualiza automáticamente, así que volvé a la página o esperá la notificación — que se envía tanto si la ejecución termina bien como si falla — para ver el resultado.
</details>

<details>
<summary>
### ¿Puedo modificar los archivos generados?
</summary>
Sí. Revisá los archivos generados desde la página de detalle de la ejecución y editalos como cualquier configuración estándar de Docker. Si la creación de Pull Request está habilitada para tu cuenta, también podés solicitar cambios directamente en el PR antes de hacer el merge.
</details>
