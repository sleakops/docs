# Instala SleakOps en tu infraestructura

SleakOps puede gestionar una infraestructura de AWS existente en lugar de aprovisionar todo desde cero. El modo de importación conecta SleakOps con infraestructura que ya tienes en funcionamiento — una cuenta de AWS, su red y un clúster EKS — sin recrear nada de eso.

Las funcionalidades de importación se habilitan por empresa — contacta a SleakOps para habilitarlas en la tuya.

## Requisitos previos

- Una cuenta de AWS con infraestructura existente para importar.
- Permisos para ejecutar stacks de CloudFormation en esa cuenta.
- Un usuario con permisos de administrador en SleakOps.

## El recorrido de importación

Importar infraestructura existente sigue una secuencia fija:

1. [Importa el provider](/docs/install-on-your-infra/import-provider).
2. Importa las cuentas.
3. Configura la red.
4. Importa el clúster.
